Apify REST API v2 & Developer Docs

Integrasikan Actor scraper langsung ke dalam aplikasi atau pipeline data Anda via REST API.

Trigger Run via cURL

curl -X POST "http://127.0.0.1:8000/api/v2/acts/tokopedia-scraper/runs" \
     -H "Content-Type: application/json" \
     -d '{"search_query": "Batik Danar Hadi", "max_items": 5}'

Fetch Dataset Items (JSON)

curl -X GET "http://127.0.0.1:8000/api/v2/datasets/{dataset_id}/items"

Download Dataset as CSV or Excel

# Download CSV
curl -O "http://127.0.0.1:8000/api/v2/datasets/{dataset_id}/csv"

# Download Excel (.xlsx)
curl -O "http://127.0.0.1:8000/api/v2/datasets/{dataset_id}/excel"
